# 🚧 Indian Road Accident Analysis Dashboard

An interactive **Power BI analytics dashboard** built to explore Indian road accident patterns across **severity, causes, locations, road types, casualties, risk scores, and time-based trends**.

The project focuses on transforming raw accident-level data into an easy-to-understand visual report that helps identify **where, when, and under which conditions accidents occur**.

## 🎯 Project Objective

The objective of this project is to analyze road accident data and create an interactive reporting solution that provides insights into:

* Overall accident volume and trends
* Accident severity and casualty patterns
* Major accident causes
* City and road-type distribution
* Geographic accident locations
* Peak-hour accident activity
* Hourly and monthly accident patterns
* Risk score distribution

---

## 📊 Dashboard Structure

### 📌 Page 1 — Accident Overview

Provides a consolidated view of overall accident activity.

**Key KPIs**

* Total Accidents
* Fatal Accidents
* Total Casualties
* Fatality Rate
* Average Risk Score

**Key Visuals**

* Accidents by Severity
* Accidents by Cause
* Accidents by City
* Accident Trend

---

### 📍 Page 2 — Location & Road Analysis

Explores accident distribution across locations and different road types.

**Key KPIs**

* Total Accidents
* Vehicles Involved
* Average Vehicles per Accident
* Average Risk Score

**Key Visuals**

* Accident Location Map
* City-wise Accident Severity
* Road Type by Severity
* Cause by Road Type
* City Risk Score

---

### 🕒 Page 3 — Time & Traffic Analysis

Analyzes accident activity across hours, days, months, and peak-traffic periods.

**Key KPIs**

* Peak-Hour Accidents
* Non-Peak Accidents
* Peak-Hour Accident %
* Average Casualties per Accident

**Key Visuals**

* Accidents by Hour
* Accidents by Day of Week
* Peak vs Non-Peak Accidents
* Accident Severity by Hour
* Monthly Accident Trend

---

## 🔍 Key Insights Covered

The dashboard enables users to explore questions such as:

* How many accidents were recorded?
* How are accidents distributed by severity?
* Which causes appear most frequently?
* How does accident activity vary across cities?
* Which road types have more recorded accidents?
* How are accidents geographically distributed?
* During which hours do accidents occur most frequently?
* How does accident activity differ between peak and non-peak hours?
* How does accident severity vary throughout the day?
* How does accident volume change over time?
