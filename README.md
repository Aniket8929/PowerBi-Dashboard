## 📌 Overview

A Power BI dashboard designed to analyze **hotel bookings, cancellations, customer behavior, market segments, and revenue performance**.

## 📊 KPIs

| KPI                        | Purpose                          |
| -------------------------- | -------------------------------- |
| **Total Bookings**         | Total hotel bookings             |
| **Total Cancellations**    | Total cancelled bookings         |
| **Cancellation Rate**      | Percentage of cancelled bookings |
| **Average ADR**            | Average Daily Rate               |
| **Total Revenue / Profit** | Overall financial performance    |

## 📈 Visuals

| Analysis                       | Visual                 |
| ------------------------------ | ---------------------- |
| Bookings by Hotel Type         | Clustered Column Chart |
| Bookings by Customer Type      | Bar Chart              |
| Booking Trend                  | Line Chart             |
| Cancellation by Hotel Type     | Stacked Column Chart   |
| Market Segment Analysis        | Bar Chart              |
| Revenue / Profit by Hotel Type | Column Chart           |
| Revenue Trend                  | Line Chart             |

## 🎛️ Filters

* Hotel Type
* Customer Type
* Market Segment
* Country
* Year
* Month

## 🛠️ Tools Used

**Power BI • Power Query • DAX • Data Modeling**

## 🎯 Objective

To transform hotel booking data into an **interactive Power BI dashboard** for identifying booking trends, cancellation patterns, customer segments, and revenue/profit performance.
